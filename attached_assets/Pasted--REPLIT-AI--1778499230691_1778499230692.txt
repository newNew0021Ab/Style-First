✅ ПРОМПТ ДЛЯ REPLIT AI

Сгенерируй полностью рабочее веб-приложение для интерактивной музейной игры (frontend + минимальная логика без backend).

📌 Концепция

Это интерактивная игра для детей на выставке.
Пользователь сканирует один QR-код и попадает на сайт.

Он проходит 5–10 простых заданий-экранов и в конце получает случайный или условно-рандомизированный “результат личности”.

📌 Технологии
Используй: HTML + CSS + Vanilla JavaScript (без сложных фреймворков, чтобы можно было легко запустить)
Всё должно работать как статический сайт
Никаких серверов и баз данных
📌 Структура приложения
1. Стартовый экран
Заголовок: "Музейная миссия"
Кнопка: "Начать игру"
Краткое описание: ты исследователь искусства
2. Игровые задания (5–10 экранов)

Каждый экран — отдельное задание с кнопками выбора.

Примеры заданий:

Найди работу, где больше всего синего цвета
Найди изображение с драконом
Какая работа кажется самой “живой”?
Выбери картину, которая похожа на сон
Какая работа вызывает радость?
Найди объект, который похож на облако

Важно:

Каждый выбор сохраняется в JS массив (answers[])
Но логика подсчета может быть простой (не сложная аналитика)
3. Финальный экран
Показ результата
Результат выбирается случайно ИЗ списка, например:
"Ты — исследователь цвета"
"Ты — хранитель драконов"
"Ты — художник сна"
"Ты — ловец историй"
"Ты — музейный путешественник"
Кнопка: "Пройти снова"
📌 Логика результата
Не нужно реального AI
Можно:
либо случайный результат
либо слегка зависимый от количества “да/нет” ответов
📌 UX требования
Очень крупные кнопки (для детей)
Яркий минималистичный дизайн
Анимации переходов между экранами (fade/slide)
Работает на телефоне идеально (mobile-first)
📌 Дополнительно (важно)
Добавь простую систему прогресса: "3 / 8 заданий"
Добавь плавные переходы между экранами
Всё должно быть в одном index.html или разделено на 3 файла (index.html, style.css, script.js)
📌 Цель

Это должно выглядеть как “интерактивный музейный квест”, простой, быстрый, без регистрации, без лагов.
